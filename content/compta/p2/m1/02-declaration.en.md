## What can be deducted

VAT charged on the price of a taxable transaction is deducted from output VAT [[cgi:art. 143]]. Some spending gives no right to deduction: housing, accommodation, catering, receptions, shows, rental of passenger cars [[cgi:art. 144]].

## The monthly return

At month end, Mbarga Distribution clears its VAT accounts:

- VAT charged: 1,925,000 CFA francs; recoverable VAT: 770,000.
- VAT due: 1,925,000 − 770,000 = **1,155,000 CFA francs**.

| Account | Debit | Credit |
|---|---|---|
| 443 VAT charged | 1,925,000 | |
| 445 Recoverable VAT | | 770,000 |
| 4441 State, VAT due | | 1,155,000 |

If recoverable VAT exceeds VAT charged, the difference is a **VAT credit** ([[syscohada:4449]]), set against later returns without time limit [[cgi:art. 149]].
