## Une réduction financière

L'**escompte** récompense un paiement rapide. C'est une réduction **financière** : elle s'enregistre toujours, même portée sur la facture [[guide:1re partie, ch. 2]].

- Chez l'acheteur : escompte obtenu, produit financier, au crédit de [[syscohada:773]].
- Chez le vendeur : escompte accordé, charge financière, au débit de [[syscohada:673]].

La TVA se calcule sur le **net financier**, après escompte.

Exemple chez l'acheteur : brut 1 000 000 ; escompte 2 % = 20 000 ; net financier 980 000 ; TVA 188 650 ; TTC 1 168 650.

| Compte | Débit | Crédit |
|---|---|---|
| 601 Achats | 1 000 000 | |
| 4452 TVA récupérable | 188 650 | |
| 773 Escomptes obtenus | | 20 000 |
| 401 Fournisseurs | | 1 168 650 |
