## Classer un élément du bilan

Deux questions suffisent le plus souvent [[guide:1re partie, ch. 1]] :

1. **Emploi ou ressource ?** Ce que l'entreprise possède ou ce qu'on lui doit est un actif ; ce qu'elle doit ou ce que les associés ont apporté est un passif.
2. **Durable ou courant ?** Un bien utilisé plusieurs exercices est immobilisé ; un bien ou une créance qui se renouvelle dans le cycle d'exploitation est circulant.

| Élément | Rubrique | Compte |
|---|---|---|
| Ordinateur de bureau | Actif immobilisé | [[syscohada:244]] |
| Marchandises en magasin | Actif circulant | [[syscohada:311]] |
| Facture client non encore payée | Actif circulant | [[syscohada:411]] |
| Facture fournisseur non encore payée | Passif circulant | [[syscohada:401]] |
| Emprunt sur cinq ans | Dettes financières | [[syscohada:162]] |
| Découvert bancaire | Trésorerie-passif | [[syscohada:561]] |

Un même compte peut changer de côté : un compte bancaire débiteur est une trésorerie-actif, un compte créditeur (découvert) une trésorerie-passif.
