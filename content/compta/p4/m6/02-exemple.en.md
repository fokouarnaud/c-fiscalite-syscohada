## At Mbarga Distribution

A lorry bought for 15,000,000 CFA francs, depreciated by 9,000,000 (NBV 6,000,000), is sold for 7,000,000 received in the bank (no VAT in this example).

| Account | Debit | Credit |
|---|---|---|
| 521 Bank | 7,000,000 | |
| 822 Proceeds from disposals | | 7,000,000 |
| 284 Depreciation of equipment | 9,000,000 | |
| 812 Carrying amount of disposals | 6,000,000 | |
| 245 Transport equipment | | 15,000,000 |

Gain: 7,000,000 − 6,000,000 = **1,000,000 CFA francs** [[syscohada:812]].
